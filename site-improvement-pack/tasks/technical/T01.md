## Goal

Make page labels and navigation reflect the new brand while preserving working static URLs.

## Why this task exists

- Current labels such as Proof, Origin and Writing are stylistic but weak for scanning and search intent.
- A full URL migration on GitHub Pages could break inbound links without a redirect layer.

## Primary target files

- `*.html`
- `sitemap.xml`
- `robots.txt`
- `qa/check.mjs`

The file list is a starting point. Inspect the current repository and include all claim or navigation mirrors affected by the change.

## Required inputs

- `qa/site-improvement-pack/context/information-architecture.md`
- `qa/site-improvement-pack/copy/navigation-and-cta.md`

Also read:

- root `AGENTS.md` if installed, otherwise `qa/site-improvement-pack/install/AGENTS.md`;
- root skill if installed, otherwise `qa/site-improvement-pack/install/.agents/skills/vadimohka-site-upgrade/SKILL.md`;
- the current target files;
- relevant rows in `evidence/claim-register.csv` and `evidence/source-register.csv`.

## Implementation requirements

- Adopt descriptive stage-one labels: Track Record, AI Diligence, Founder Advisory, Insights, About and Contact.
- Keep current physical `.html` URLs unless a verified redirect layer exists.
- Use the same primary navigation order on every page.
- Keep Media & Speaking secondary if the primary navigation becomes crowded.
- Add `aria-current="page"` to the active page.
- Ensure header and footer labels are consistent.
- Update sitemap labels only through URLs; do not add non-indexable or dev-pack files.
- Enhance QA to compare navigation destinations across pages.
- Document any deferred end-state URL migration.

## Non-goals

- No cosmetic URL migration.
- No duplicate physical pages.
- No hreflang.

## Acceptance criteria

- All pages expose the same coherent navigation.
- Every label describes the page intent.
- All legacy URLs continue to resolve.
- Only one active page is marked with `aria-current`.
- Sitemap contains canonical indexable pages only.
- `node qa/check.mjs` passes.

## Verification

- Extract and compare nav links from all production HTML.
- Crawl all local links.
- Review at 320 and 1440 px; T02 will own the mobile interaction.

Always run:

```bash
node qa/check.mjs
```

Run any additional task-specific test introduced by the implementation.
