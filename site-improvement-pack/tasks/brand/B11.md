## Goal

Align the website's entity with LinkedIn, GitHub, legacy .ru, Setka, Scholar, Codeforces and Stepik.

## Why this task exists

- At audit time, external profiles presented multiple primary identities and the legacy .ru site competed with the .com message.
- Codex may not have authenticated access to change third-party profiles, so it must separate recommendations from completed actions.

## Primary target files

- `reports/external-profile-actions.md`
- `sources.html`
- `data/entity-graph.json`

The file list is a starting point. Inspect the current repository and include all claim or navigation mirrors affected by the change.

## Required inputs

- `qa/site-improvement-pack/evidence/external-profile-consistency.md`
- `qa/site-improvement-pack/context/brand-strategy.md`
- `qa/site-improvement-pack/evidence/source-register.csv`

Also read:

- root `AGENTS.md` if installed, otherwise `qa/site-improvement-pack/install/AGENTS.md`;
- root skill if installed, otherwise `qa/site-improvement-pack/install/.agents/skills/vadimohka-site-upgrade/SKILL.md`;
- the current target files;
- relevant rows in `evidence/claim-register.csv` and `evidence/source-register.csv`.

## Implementation requirements

- Re-check every external profile in `evidence/external-profile-consistency.md` when network access is available.
- Create `reports/external-profile-actions.md` with observed text, risk, exact replacement, owner action and completion status.
- Use one master identity and exact current titles.
- Recommend a clear legacy .ru strategy: redirect, true Russian alternate, or deprecation.
- Do not add hreflang until complete language alternates exist.
- Re-check the Setka job-search status and flag it only if still present.
- Align `sameAs` links with real profiles and remove weak or incorrect relations.
- Do not claim an external profile was changed unless the action actually succeeded.
- Record all off-site owner actions separately from repository changes.

## Non-goals

- No fake completion status.
- No Wikipedia/Wikidata creation without independent notability.
- No automated login or credential handling.

## Acceptance criteria

- The action report covers LinkedIn, GitHub, .ru, Setka, Scholar, Codeforces, Stepik, StackLevel and Century.
- Every proposed headline follows the brand strategy.
- Current site `sameAs` links are valid and relevant.
- Uncompleted external actions are clearly marked.
- `node qa/check.mjs` passes if repository files changed.

## Verification

- Open each current profile where possible.
- Compare exact title, spelling, role, site URL and primary territory.
- Validate all `sameAs` URLs.

Always run:

```bash
node qa/check.mjs
```

Run any additional task-specific test introduced by the implementation.

This task must be revertible without reverting unrelated tasks. Do not mix opportunistic cleanup into the same change.
