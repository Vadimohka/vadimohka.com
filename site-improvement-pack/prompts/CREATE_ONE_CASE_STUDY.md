# Create one evidence-led case study

Use this only after the owner has supplied a completed case intake.

## Inputs

- completed `templates/case-study-intake.md`;
- relevant claim and source records;
- NDA/publication permissions;
- current target page.

## Rules

- Do not fill missing fields by inference.
- Separate personal mandate from team/company contribution.
- Keep named clients private unless permission is explicit.
- Do not use unmeasured adjectives.
- Use exact dates or ranges.
- Explain constraints and decisions.
- Include an outcome only when it is measurable or independently verifiable.
- Include a source or classify as owner-confirmed.
- Use a confidentiality note only for genuinely non-disclosable detail.

## Output

Draft one case study using:

Context → Decision → Personal mandate → Constraints → Work → Scale → Outcome → Verification.

Then produce:

- a full Track Record version;
- a 60–90 word homepage proof card;
- a 30-word metadata/OG-safe summary;
- claim ledger updates required.

Do not publish it automatically.
