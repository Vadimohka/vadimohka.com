# Non-negotiables

## Architecture

1. Keep the site static.
2. No framework migration.
3. No production dependency unless the owner explicitly changes this rule.
4. Development-only tooling is acceptable when it creates repeatable QA and is excluded from production output.
5. Preserve working inbound URLs.
6. Preserve the existing high-level visual identity unless a task specifies a targeted change.

## Truthfulness

1. No invented metrics, clients, engagements, testimonials, media, roles, credentials, or dates.
2. No conversion of a company-level fact into a personal achievement.
3. No implication that a planned service is an established track record.
4. No vague educational affiliation: exact programme, credential, and dates or omission.
5. No visible placeholders.
6. No unpublished owner-input file committed to the repository.
7. No production TODO comments describing missing evidence.
8. No claim strengthening based on design intent alone.

## Positioning

1. Primary archetype: operator / CTO / technical founder.
2. Primary territory: governed private enterprise AI for regulated organisations.
3. Investor relevance is technical diligence, not investment authority.
4. Founder relevance is product and engineering judgement, not fundraising, growth, or introductions unless separately evidenced.
5. Speaking and media are supporting authority, not a primary commercial identity.
6. Avoid “visionary”, “global leader”, “world-class”, “leading expert”, “serial entrepreneur”, and “thought leader”.
7. Reduce “serious”, “high stakes”, “real”, and “trusted” when they are not followed by concrete proof.

## Evidence

A production claim is allowed only when it is:

- independently verified;
- owner-confirmed and appropriately scoped;
- or clearly presented as current focus, method, or point of view rather than achieved outcome.

## UX

1. The first screen must answer who, what, for whom, level, industry, proof, and next action.
2. Mobile navigation may not rely on discovering horizontal scroll.
3. Meaningful text should target at least 12 px.
4. Normal text contrast should meet WCAG AA.
5. All interactive controls require visible focus and keyboard operability.
6. Reduced-motion preferences must be respected.

## SEO and machine-readable content

1. Visible copy and structured data must tell the same story.
2. `sameAs` contains only real profiles controlled by or clearly referring to the person.
3. Article schema is used only for real articles.
4. Hreflang is used only when full alternate pages exist.
5. AI-oriented files do not receive looser claim standards than visible pages.
6. No rankings, traffic, backlinks, PageSpeed, CWV, or conversion claims without current measurement.

## Release

A task is not done because the HTML looks plausible. It is done only when:

- acceptance criteria pass;
- QA passes;
- claims are sourced;
- mobile and keyboard impact is checked where relevant;
- machine-readable mirrors are synchronised;
- the diff contains no unrelated changes.
