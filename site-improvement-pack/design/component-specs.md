# Component specifications

## Authority chip

Use for exact, compact credentials.

Required:

- short label;
- optional date;
- source link or association to a sourced record;
- no paragraph copy.

Examples:

- CTO · StackLevel Group
- Century · AI Product Leader, 3rd place · 2025

Do not use for:

- generic sectors;
- beliefs;
- “serious environments”;
- unverified metrics.

## Outcome card

Required fields:

- date/range;
- outcome-led title;
- context;
- personal mandate;
- measurable/verified result;
- source link.

Visual priority: high.

## Public-work record

Required fields:

- format;
- outlet/event;
- date;
- exact title/topic;
- role;
- direct link.

Visual priority: medium.

## Audience decision card

Required fields:

- audience/decision context;
- trigger condition;
- deliverable or value;
- specific CTA.

Do not list flattering audience labels without explaining relevance.

## Source link

Text should identify the source:

- Read the Finance Mail.ru article.
- View the official IT-Security programme.
- View the Hi-Tech Park award announcement.

Avoid four identical “Source” links in a card grid without accessible context.

## Inquiry route

Required fields:

- inquiry type;
- when to use it;
- what to include;
- functional action.

Must work without JavaScript.

## Mobile menu

- native button;
- state attributes;
- visible label/icon;
- expanded panel;
- focus and Escape behavior;
- no hidden tabbable links;
- no horizontal-scroll discovery.

## Decorative marquee

If retained:

- `aria-hidden="true"` when it repeats visible concepts;
- sufficient visual contrast if intended to be read;
- disabled under reduced motion;
- does not obscure content or create a false evidence layer.
