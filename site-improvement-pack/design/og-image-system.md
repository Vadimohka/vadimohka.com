# Open Graph image system

## Goal

Different page intents should produce recognisably different share previews without creating runtime weight.

## Format

- 1200 × 630 px.
- WebP or JPEG with broad platform support.
- Keep text inside safe margins.
- Use a real portrait or product/diagram asset only when rights and quality are clear.
- Use system/editorial typography; do not bundle font files.

## Rules

- Do not put unsupported metrics on an OG image.
- Do not use “award-winning CTO”; the verified placement belongs to Century.
- Page metadata and image text must agree.
- Validate readability at small preview sizes.
- Include dimensions in metadata where appropriate.
